# Project Title

Django Advanced API

## Description

A simples django API using REST Framework

## Getting Started

### Dependencies

* Virtual Environment created (.venv) 
* pip install django
* pip install djangorestframework
* After create all models:
* python manage.py makemigrations
* python manage.py migrate


### Executing program

* How to run the program
* python manage.py runserver
```
python manage.py runserver
```
